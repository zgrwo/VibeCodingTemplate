## What This Project Is

{{PROJECT_NAME}} is a project initialized from a **meta-project governance template** — the template is not a specific application, but a governance framework you clone to start a new project. It encodes senior-engineer project governance knowledge into machine-readable, auto-verifiable rules.

**Core governance problems it addresses:**

1. **AI hallucination governance** — AI assistants invent APIs, cross architectural boundaries, ignore constraints. This project carries AGENTS.md (project constitution) + anti-hallucination rules + closed-loop verification scripts.
2. **Documentation drift** — Function counts, signatures, and structure info get hardcoded in multiple places. The template enforces SSOT (Single Source of Truth) with automated consistency checking.
3. **Engineering knowledge transfer** — New projects start from zero. The template distills anti-pattern case libraries from real projects' commit histories into executable rules.

## Quick Start

<!-- TEMPLATE_ONLY_START -->
### Initializing a new project from this template (interactive)

```powershell
# Windows (PowerShell)
.\scripts\init-project.ps1 -Target C:\Projects\{{PROJECT_NAME}} -GitInit
```

```bash
# Linux / macOS (Python 3.10+)
python scripts/init-project.py /path/to/{{PROJECT_NAME}} --git-init
```

### Option B: Scripted initialization (recommended for CI / Windows)

```bash
# values.json carries only project-defining keys; everything else has defaults
python scripts/init-project.py /path/to/{{PROJECT_NAME}} --non-interactive --values-file values.json
```

> Prefer `--values-file` over `--values`: Windows PowerShell 5.1 strips the double quotes
> inside a command-line JSON argument, which makes `--values` fail with a JSON parse error.
> PowerShell users can also pass a native hashtable: `-Values @{ PROJECT_NAME = "..." }`.
<!-- TEMPLATE_ONLY_END -->

### Verify

```bash
# Cross-platform (Python)
python scripts/verify-all.py

# Windows only (PowerShell)
.\scripts\verify-all.ps1
```

> **Note:** verification scripts print in Chinese by default. This is by design for the primary audience; the flags and exit codes are language-neutral.

## Placeholder System

This project is generated by scanning for `{{...}}` placeholders and replacing them. Two syntaxes exist:

| Syntax | Level | Replaced by |
|--------|-------|-------------|
| `{{...}}` | Project-level | `init-project` auto-replacement (e.g. `{{...}}`) |
| `{PascalCase}` | Module-level | Manual replacement inside `templates/NewModule/` (e.g. `{Name}`, `{Module}`) |

The full placeholder manifest (category / default / test value) lives in `scripts/placeholders.json` — the single source of truth read by `init-project` and `test-template.ps1`. The CI template-self-test job fails if a manifest entry is declared but unused, or a used placeholder is undeclared.

Template-only sections in this repo's own docs (e.g. the "从本模板初始化新项目" init guide in `README.md`) are delimited by `<!-- TEMPLATE_ONLY_START -->` / `<!-- TEMPLATE_ONLY_END -->` HTML comments and are **stripped** by `init-project` during initialization — they describe the template itself and must not leak into generated projects. Convention documented in `docs/governance/documentation.md`.

```
        ↓

```

## Governance System

> Document ownership & maintenance rules (single authority): `docs/governance/documentation.md`. This table is a quick navigation index.

| File | Audience | Responsibility |
|------|----------|----------------|

| `docs/` | AI + humans | Doc hub — spec sources (spec/), governance (governance/), design & ADRs (design/), pitfalls (pitfalls/), methodology (methodology/) |

| `CONTRIBUTING.md` / `CHANGELOG.md` / `LICENSE` | Collaboration & compliance | Contribution flow, version history, open-source license |

**Core principles**: SSOT (every fact defined once, referenced elsewhere), Skill-first (load the skill before touching code), four core principles (Think First / Simplicity First / Surgical Changes / Goal-Driven), closed-loop verification.
