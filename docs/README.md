# docs/ — 项目文档

> 本目录存放**领域设计文档**（非规则文档）。与 `rules/` 的分工：
>
> | 位置 | 面向 | 内容 |
> |------|------|------|
> | `rules/` | 规范 | API 参考、用户手册、术语表、ADR、陷阱清单（**唯一信源**） |
> | `docs/` | 设计 | 设计决策说明、验证报告、专题研究（支撑性资料） |

## 现有文档

| 文件 | 内容 |
|------|------|
| `architecture.md` | 模板仓库自身架构设计（含 ADR 决策记录） |

## 约定

- 新增设计文档必须从 `rules/` 中已有信源引用，**禁止在 docs/ 重复定义**业务规则
- 重要设计文档发布时同步登记到 `rules/` 对应文档与 `AGENTS.md` 目录树
- 过期文档及时归档或删除，避免「两份文档打架」
